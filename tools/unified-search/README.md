# מאחד מאגרי דמו

אבטיפוס מקומי שמחפש מזהים בין קבצים ומציג את הרשומות שמכילות התאמה. הוא נועד לבדיקה על נתוני דמו/נתונים שיש הרשאה לעבד.

## מה הוא עושה

- קורא CSV, TSV, TXT, SQL ו-XLSX.
- מזהה אימיילים וטלפונים גם בתוך קבצי טקסט ו-SQL גדולים.
- מנרמל אימיילים וטלפונים כדי לחבר פורמטים שונים.
- שומר מקור, מספר שורה ושדות של כל התאמה.
- מציג את כל המקורות בקבוצה אחת כאשר נמצא אותו מזהה.
- מסתיר ערכים של שדות רגישים לפי שם השדה, כגון password, CVV, token ומספר כרטיס.
- עובד מקומית בלבד; אין שליחה לשירות חיצוני ואין צורך במפתח API.

## הפעלה

```bash
cd /home/ubuntu/data_unifier
python3 indexer.py /home/ubuntu/demo_extract --db unified.sqlite
python3 app.py unified.sqlite
```

לאחר מכן לפתוח: `http://localhost:5000`

אם רוצים לבדוק מהר לפני אינדוקס מלא:

```bash
python3 indexer.py /home/ubuntu/demo_extract --limit-files 5 --db demo.sqlite
python3 app.py demo.sqlite
```

## הערות חשובות

- קבצי ZIP/7Z/RAR פנימיים אינם נפתחים אוטומטית בגרסה הזו; אפשר לחלץ אותם בנפרד ולהריץ שוב על התיקייה.
- קבצי SQL מעובדים בסריקה בטוחה של טקסט, לא בהרצת SQL. כך אין סיכון להריץ פקודות מתוך dump.
- האיחוד הנוכחי הוא התאמה דטרמיניסטית לפי אימייל/טלפון/שדות שמרמזים על מזהה. הוא אינו טוען ששתי רשומות הן אותו אדם רק על בסיס שם דומה.
- לפני שימוש על מידע אמיתי יש להגדיר הרשאות, מדיניות שמירה, הצפנה ובקרת גישה.
